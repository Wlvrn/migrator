How to Use


            
Two modes

            
    
                
  • 🔍 Analyse — scans your HTML and produces a severity-tiered report (CRITICAL / HIGH / MEDIUM / LOW / MANUAL REVIEW) without modifying anything. Use this first to understand scope.
    • 
                
  • Migrate → — applies all auto-fixable transformations, then shows a post-migration residual analysis of anything still needing manual attention.
    • 
            


            
Workflow

            
    
                
  1. Paste Bootstrap 3 HTML (or upload a .vbhtml / .cshtml file)
    2. 
                
  2. Click Analyse — review the Analysis tab for severity breakdown
    3. 
                
  3. Click Migrate — auto-fixes are applied; residual manual items appear in Analysis
    4. 
                
  4. Copy output or download the migrated file
    5. 
            


            
What gets auto-fixed

            
    
                
  • data-toggle/dismiss/target → data-bs-* renames
    • 
                
  • Grid: col-xs-* → col-*, offset renames
    • 
                
  • Utilities: pull-*, text-*, hidden-*, visible-*
    • 
                
  • Components: panels → cards, wells → cards, labels → badges
    • 
                
  • Forms: form-group, control-label, help-block, validation states
    • 
                
  • Navbar: icon-bar, navbar-header, caret removal, nav-item/nav-link injection, navbar-expand-lg
    • 
                
  • Alert dismiss: .close → .btn-close
    • 
            


            
What needs manual review

            
    
                
  • Dynamic class construction in backend strings ("btn btn-" + type)
    • 
                
  • jQuery plugin calls (.modal(), .popover(), .collapse())
    • 
                
  • Razor HTML helper attributes in .vbhtml/.cshtml
    • 
                
  • bootstrap-theme.css removal
    • 
                
  • bootstrap.js → bootstrap.bundle.min.js swap
    • 
                
  • BundleConfig.cs: ScriptBundle → Bundle for Bootstrap JS
    • 
            


            
Limitations

            
    
                
  • Strip Razor syntax before migrating — use the Upload File button for .vbhtml/.cshtml (auto-stripped)
    • 
                
  • BundleConfig.cs and backend C#/VB string HTML cannot be processed here — use the Claude Code prompt in the repo
    •
